# مستند فنی مدل smooth2

این پوشه خروجی رسمی و قابل استفادهٔ مدل پارامتریک smooth2 است. فایل‌های هندسی آن از سازندهٔ اصلی در `cad/parametric/drone_parametric.py` و دادهٔ مقاطع `cad/parametric/body_sections.json` تولید می‌شوند.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `drone_parametric.step` | اسمبلی STEP با ساختار ۲۶ جزئی |
| `drone_parametric.stl` | خروجی STL پیش‌فرض؛ چیدمان انفجاری |
| `drone_parametric_assembled.stl` | چیدمان مونتاژشده |
| `drone_parametric_exploded.stl` | چیدمان انفجاری |
| `drone_parametric.params.json` | snapshot پارامترهای همان اجرا |
| `assembly-manifest.json` | فهرست اجزا و اطلاعات مونتاژ |
| `validation-report.json` | ابعاد، کنترل‌های هندسی و نتایج آزمون خروجی‌ها |
| `body_lower`, `body_crown`, `arm_1..4`, `prop_1..4`, `screw_1..8`, `nut_1..8` | فایل مستقل STEP و STL هر جزء |

## ساختار اسمبلی

مجموعاً ۲۶ جزء مستقل وجود دارد:

- ۱ پوستهٔ پایینی با کف بسته و پیوسته؛
- ۱ تاج یا پوستهٔ بالایی؛
- ۴ مجموعهٔ بازو با محافظ و محل موتور؛
- ۴ پروانه؛
- ۸ پیچ نمایشی؛
- ۸ مهرهٔ نمایشی.

بازوها از ورودی‌های جانبی بدنه وارد می‌شوند. ریشهٔ هر بازو به فرم دوشاخهٔ تیک‌شکل طراحی شده و اتصال آن با پیچ‌های عمودی از زیر بدنه انجام می‌شود؛ اتصال پیچ به دیوارهٔ کناری در طرح وجود ندارد. فرورفتگی‌های مهره در سطح بیرونی زیر بدنه قرار دارند.

## کنترل‌های هندسی

سازنده و کنترل خودکار، موارد زیر را بررسی می‌کنند:

- تعداد اجزای اسمبلی و solidهای STEP؛
- صحت و watertight بودن تمام STLهای تولیدشده؛
- واردسازی مجدد STEPهای اسمبلی و قطعات؛
- عبور سوراخ‌های پیچ از کف و قرارگیری فرورفتگی مهره در زیر بدنه؛
- حفظ ضخامت اسمی کف در نمونه‌برداری مرکزی؛
- زاویه و ابعاد ریشه‌های تیک‌شکل؛
- فاصلهٔ پروانه با موتور، بازو و محافظ.

نتایج دقیق هر فایل در `validation-report.json` ذخیره می‌شوند.

## تولید مجدد

از ریشهٔ مخزن اجرا کنید:

```bash
python -m pip install cadquery numpy trimesh
python cad/parametric/drone_parametric.py
```

پارامترها را در سازنده تغییر دهید یا snapshot جایگزین را با `--params` بدهید. فایل‌های خروجی را دستی ویرایش نکنید.

## جهت و واحدها

واحد هندسه میلی‌متر است. خروجی نهایی با محور Z رو به بالا تنظیم شده است. جهت جلوی پهپاد و محور دوربین به سمت `-Y` است و سطح زیرین صاف به سمت `-Z` قرار دارد.

## مواردی که هنوز باید پیش از ساخت واقعی تعیین شوند

- سوراخ و تلرانس شفت موتور باید مطابق موتور واقعی طراحی و کنترل شود.
- پیچ و مهره‌های داخل مدل فقط حجم‌های نمایشی بدون رزوه‌اند؛ برای مونتاژ واقعی از سخت‌افزار فلزی مناسب استفاده شود.
- روش اتصال و قفل‌شدن تاج روی پوستهٔ پایینی هنوز تعریف نشده است.
- لقی چاپی، تلرانس قطعات، استحکام بازوها، خستگی، ارتعاش و بالانس پروانه با آزمون فیزیکی تعیین نشده‌اند.
- قبولی CI یا watertight بودن مش به‌تنهایی به معنی آماده‌بودن قطعه برای پرواز نیست.
